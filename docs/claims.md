# 事实核验与对外表述

核验日期：2026-09-21。实现以本仓库代码为准，接口以官方文档及真实调用为准。

| 常见说法 | 本项目采用的表述 |
|---|---|
| JEV 不会说话 | API 返回限定类型的判断结果；不提供通用对话体验 |
| 无需解析 | 不必从模型自由文本中提取答案；HTTP 响应仍需 JSON 解码、字段与数值校验 |
| 没有幻觉 | 限定输出空间减少选项外输出；选项内仍可能判断错误，缺失候选也会影响判断 |
| 概率与置信度就是正确率 | Choice 的概率分布和由分布导出的 confidence 都不是业务成功率或授权 |
| 高概率自动执行 | 仅可在授权、确定性规则及业务评估支持的范围内设计自动动作；本项目不执行动作 |
| 延迟 70–500ms、快 20–200 倍 | 不作为本项目实测或承诺；须定义基线并测端到端耗时 |
| 输入每百万 token 0.042 美元、输出免费 | 不写入成本承诺；开通时查供应商当前计费，记录实际 usage 和账单 |
| 判断层价值的“万有公式” | 最多作为启发性比喻；可靠性、并行度与成本并非总能简单乘除，格式损耗为零时公式也失去意义 |
| 生成式大模型只能自由文本再修 JSON | 不成立，比较基线应包含结构化输出或工具调用，避免拿劣化基线做宣传 |

本次通过官方 HTTP API 页面核对请求地址、鉴权方式、Choice/Noul 类型、响应字段；通过官方 function calling 示例核对“限定选项到程序分派”的设计思路。API 示例给出 `jev-1.13.0`，本实现将其固定为默认值，可显式配置。

参考来源：

- [TypeSafe API](https://docs.typesafe.ai/api)：HTTP 契约、三种原语、返回字段和错误码。
- [TypeSafe Function calling](https://docs.typesafe.ai/cookbooks/function_calling)：类型化函数分派的官方示例；本项目没有复制其交易业务逻辑。
- [TypeSafe Confidence](https://docs.typesafe.ai/confidence)：置信度说明入口。

本项目改编自作者已有的 Agent 辅助 Harness 实现，并重新核验本目录中的代码。没有复制新闻原文、私人聊天、客户数据、内部系统截图或既有运行记录。既有部署不构成本版本验收证据。
